# RYF Nueva

Nueva versión estática de la web del Dr. Ricardo Yagüe Facal para GitHub Pages.

- Incluye todas las páginas y recursos de la réplica `ryf`.
- La página principal incorpora el nuevo diseño centrado en marca, tradición familiar, atención personal y precisión clínica.
- Fuente de trabajo en Beebox: `/home/livin/gDrive/gitHub/ryfnueva`.
- URL prevista: `https://ricardoyf.github.io/ryfnueva/`.

La publicación se sirve desde la raíz de la rama `main`. El archivo `.nojekyll` evita que GitHub Pages procese la copia como un proyecto Jekyll.
